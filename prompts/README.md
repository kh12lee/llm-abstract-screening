## Prompts

This folder contains prompt templates separated from code.

- `system_v1.txt`: system message used in experiments.
- `cholangio_ontology_v1.txt`: domain ontology and inclusion criteria for the cholangio dataset.
- `nsclc_ontology_v1.txt`: domain ontology and inclusion criteria for the NSCLC dataset.

Versioning:
- Update the suffix (v2, v3, ...) when you materially change wording.
- The pipeline stores SHA-256 hashes of the exact prompt strings in `*.run_meta.json` for traceability.
