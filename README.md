# LLM-assisted abstract screening

This repository contains the analysis code and prompts used for the LLM-assisted abstract screening experiments reported in our manuscript submitted to *Research Synthesis Methods*.

## Contents
- `notebooks/Cholangio_Ontology.ipynb`: main analysis notebook
- `prompts/`: system message and screening prompt used in the study

## Requirements
Python 3.10+ recommended.
